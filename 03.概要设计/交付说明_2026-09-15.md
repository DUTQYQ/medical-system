> ① 手写脚本 → `mysql < schema.sql` + `mysql kangyang < init_data.sql`；

## 七、如何重建（改内容后一条命令全量刷新）

```bash
cd "03.概要设计/_gen"
python figures.py        # 出图 → 图_v2/
python build_md.py       # 出正文 → 概要设计说明书_康养系统_v2.0.md
python build_dict.py     # 出数据字典 → 04.编码/数据库/数据字典_康养系统_v1.0.xlsx
python build_docx_v2.py  # 出 Word  → 概要设计说明书_康养系统_v2.0.docx
```

> 内容全部由 `_gen/` 下的数据文件驱动，**不要直接编辑 md 或 docx**，否则下次重建会被覆盖。
> 模块功能点改 `data_modules.py`，接口函数改 `data_funcs.py`，表结构改 `04.编码/数据库/schema.sql`。
