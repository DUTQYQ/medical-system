# 康养系统代码实现与验收记录

日期 2026-10-08。本次将既有 Vue 页面从模拟数据切换到真实接口，新增 FastAPI 后端、护工端及管理员端，完成项目核心预警闭环。验收区分代码与离线测试、隔离 MySQL 业务测试、现有数据库只读连接，以及尚未验证的真实模型能力；不将测试替身等同在线模型。

## 实现范围

认证包含角色白名单、bcrypt、JWT、服务端持久注销、账号禁用立即失权、改密码及角色变更撤销旧 Token、登录失败限次、隐私授权和个人资料修改。

健康档案支持 1 至 N 份、创建查看修改与软删除。老人、家属、护工及管理员按实时归属、已确认绑定或在管关系隔离数据；代建档案必须来自既有授权，不自动扩大其他人员权限。指标支持血压、血糖、心率、睡眠和步数，记录校验、分页历史、删除和趋势图。

阈值与录入配置保存于 `sys_config`。异常指标、预警、接收人由同一事务写入，模型摘要在后台生成。接收人的已读状态和全局处理状态独立；处理说明、人员及时间留痕。解绑和护工撤销分配立即收回历史访问权限。新授权人员可查看历史预警，通知状态不充当访问权限。

护工端包含负责老人、异常优先、测量时段筛选、详情、代录、预警与本人处理记录。管理端包含建号、启禁、角色、档案、阈值、指标范围、知识增删改及索引、周期统计与数据总量。四端包含空数据、失败、无权限和过期状态。

AI 包含 LangGraph 四类意图数据路径、国内三提供方环境切换、输入长度与日限额、紧急关键词及同义表达强制升级、诊断和调药输出过滤、异步摘要及重试。RAG 实现 Embedding、Chroma、分块、Top-K 与知识变更重建，附七类有官方来源的基础科普语料。

两项 MySQL 并发测试分别验证：两位接收人同时处理同一预警，只写入一份最终处理记录；同一用户并发申请同一绑定，只生成一份有效申请。临时数据库在测试后删除，现有业务数据库没有被重建或清空。

浏览器重点路径为老人录入异常血压、家属收到通知、打开详情、登记处理和查看记录。另实测四角色登录和隐私授权、管理端建号启禁及配置写入、多档案创建与隔离、过期 Token、403、网络中断、无 Key 的 AI 降级、趋势图和统计 canvas。最终补测护工异常、已处理与中文已读标签，更新当前截图；45 项命名检查均通过，页面错误列表为空。预期触发的 400 或网络错误有显式提示。

测试源文件为 `后端/tests`、本目录 `test_acceptance.py` 与 `verify_mysql.py`，浏览器证据为 `前端浏览器` 下脚本、JSON 和 PNG。实际 OpenAPI 提供 62 个 HTTP 方法与路径组合，含兼容别名及健康检查；原契约及新增核心接口以《API 接口实现补充 v0.2》共同为准。

## 验证限制与运行状态

真实模型 Key 未配置，未验证 DeepSeek、通义千问或 GLM 在线回答、成本、延迟及模型故障恢复质量。代码缺 Key 时返回 3001；录入、预警和处理仍可运行。AI 测试中的回答不是生产成功记录。

默认哈希向量只验证词形检索。七类真实来源语料的典型问题在 Chroma Top-3 中命中，不代表所有近义问法均能正确召回。可选本地语义模型适配器的加载约束经过测试，真实语义模型未安装验收。七条起始科普不是完整疾病知识库，当前已有 MySQL 尚未导入它们。

既有 MySQL 演示阈值部分缺少低值覆盖；应用会明确提示管理员补齐，不能静默判正常。原 SQL 种子还存在异常标记及风险等级口径不一致，本次保留原有数据库及用户修改的备份，隔离演示通过实际录入生成预警，避免将旧种子当成当前逻辑证据。

【选配】短信、电话外呼、流式输出、文档上传及 PDF 导出未做接入验收。用药和打卡本地记录已标明没有服务器同步。遗留摘要自动恢复只适用单进程，生产默认关闭，开启方式见运行说明。
