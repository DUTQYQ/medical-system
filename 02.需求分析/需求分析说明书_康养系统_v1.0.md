## 1. 项目概述

### 1.1 项目背景
中国老龄化程度持续加深，传统康养服务面临使用门槛高、健康数据分散、异常体征无法及时告知家属、咨询缺少个性化、数据与服务未形成闭环五大问题。随着 AI 大模型技术成熟，构建一个**面向老年人的 AI 主动式健康管理平台**成为可行解。

### 1.2 项目目标
- **目标一 · 降低使用门槛**：适老化设计——【核心】大字号 ≥18~24px、高对比、少层级、大按钮 ≥48px；【选配】语音输入 STT、语音播报 TTS
- **目标二 · 统一健康档案**：用户 → 档案 → 指标 → 历史记录的完整数据体系（【核心】）
- **目标三 · AI 健康助手**：结合档案 + 历史数据 + 知识库（RAG）回答老人自然语言健康问题（【核心】）
- **目标四 · 主动预警机制**：后台持续分析健康数据，超阈值自动分级预警并推送家属/护工（核心卖点）
- **目标五 · 形成康养闭环**：数据采集 → AI 分析 → 咨询 → 异常检测 → 预警 → 家属/护工处理 → 处理记录（【核心】）

### 1.3 建设范围（In Scope）
1. 4 类角色：老年用户 / 家属 / 护工 / 系统管理员
2. 用户注册登录、角色权限（JWT 鉴权）
3. 老人健康档案 + 健康指标数据 + 趋势图
4. AI 健康咨询（意图路由 + RAG 知识库 + 大模型回答）
5. AI 主动预警（阈值规则引擎 + 风险分级 + 分级通知 + 处理闭环）
6. 家属端（绑定老人 / 代管 / 接预警）
7. 护工端（管理负责老人 / 处理预警）
8. 管理员后台（用户 / 角色 / 阈值 / 知识库 / 统计）

### 1.4 非建设范围（Out of Scope）
- ❌ 不接真实医院/体检机构数据（无接口）
- ❌ 不做紧急医疗报警/医生远程诊断（责任与合规风险，仅做"建议就医"引导）
- ❌ 不训练/微调大模型、不本地部署 LLM（成本高、组内零基础）
- ❌ 不做移动 App（本期 Web 优先，响应式适配手机）
- ⚠️ 系统给出的是健康建议/科普，**不构成医疗诊断**——需在页面固定声明

| 家属（F） | 帮父母管理健康、代为咨询、接预警 | 绑定多位老人、看历史记录、及时收到异常通知 | FAMILY |
| 护工（C） | 社区/机构护工，管理多名老人 | 老人状态一目了然、查看并处理预警 | CARE |
| 系统管理员（M） | 项目组/运营方 | 用户/角色/阈值/知识库/统计管理 | ADMIN |

## 4. AI 智能体需求（评审重点）

### 4.1 技术路线
- 国内大模型 API：**【候选：DeepSeek / 通义千问 / 智谱GLM —— 待组内定】**，可配置切换
- 后端服务封装 prompt（系统提示词 + 档案摘要 + RAG 检索结果 + 问题）→ 调用 API → 返回
- LangChain / LangGraph 编排多 Agent；不训练/微调模型；不本地部署

### 4.2 Agent 架构（答辩核心）
```
START
 → 意图识别 Agent（普通咨询 / 数据问题 / 异常 / 紧急 路由）
    ├─ 普通咨询 → Health Agent（RAG 检索 + 个性化回答）
    ├─ 数据类   → Health Data Agent（查库 + 趋势分析 + 回答）
    ├─ 异常     → Risk Agent（风险分级 + 生成预警 + 通知）
    └─ 紧急     → Emergency Agent（建议就医 + 触发紧急通知）
Alert Agent（后台守护）：新数据 → 合法性校验 → 阈值检测 → 历史趋势 → 风险分级 → AI 预警摘要 → 通知家属/护工
```

### 4.3 安全分级（L1~L4）
| 级别 | 场景 | 系统行为 |
|---|---|---|
| L1 | 普通咨询（每天走多少步） | 正常回答 |
| L2 | 健康建议（睡眠不好怎么办） | 生活方式建议 |
| L3 | 异常数据（血压 165/100） | 风险提示 + 建议就医 + 触发预警 |
| L4 | 紧急表述（胸痛/呼吸困难） | 不闲聊，立即建议求助 + 通知紧急联系人 |

> 页面固定免责声明："内容仅供参考，不构成医疗诊断。"

### 4.4 风险与对策
| 风险 | 对策 |
|---|---|
| AI 输出幻觉/不当医疗建议 | 系统提示词限定 + L1~L4 分级 + 免责声明 + 敏感词过滤兜底 |
| API 费用/限流 | 选低价国内模型；单次限字数；控制频率；多模型切换配置 |
| 老人不会打字 | 预设常见问题按钮 + 🧩语音输入（Web Speech 零成本） |
