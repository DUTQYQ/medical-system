## 3. 非功能需求（RTM 关联项）

| 类别 | 要求 |
|---|---|
| 性能 | 页面响应 < 3s；AI 回答（流式可选）5~15s |
| 安全 | 密码 bcrypt 加密；登录态 token；数据权限隔离；API Key 不暴露前端 |
| 可用性（适老化） | 默认字号 ≥ 16px；对比度达标；按钮 ≥ 44px；主流程 ≤ 3 步；可一键朗读 |
| 兼容 | Chrome/Edge 现代浏览器 |
| 数据备份 | 数据库定期导出（开发期每周） |
