## 为什么归档而不是删除

1. 9/11 原型评审的结论针对的是这一版的具体页面，删除后无法复核。
2. v2.0 把编号从 `P1~P9` 改为与《界面清单》一致的 `UI-XXX-NN`，并补齐到 38 个界面；
   归档可用于说明"改了什么、为什么改"。
3. 归档目录内的 `prototype.css` 是快照副本，上级 `prototype.css` 后续变更不会影响本目录渲染。
