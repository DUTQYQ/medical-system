# 康养系统代码运行说明

版本 1.0，日期 2026-10-08。本文供项目成员启动、联调和演示当前代码。老人、家属、护工、管理员四端均调用真实后端；健康指标经配置规则自动生成预警，家属或护工处理后留下记录。AI 未配置或失败时，该业务闭环仍可运行。

## 环境与启动

使用 Python 3.11、Node.js 18 或以上及 MySQL 8。后端依赖在 `04.编码/后端/.venv`，前端依赖在 `04.编码/前端/node_modules`。本次已经安装并通过测试；重新部署可使用启动脚本的 `-Install` 参数安装。

### 一键启动（推荐）

在项目根目录打开 PowerShell：

```powershell
& './一键启动.ps1' -Demo
```

脚本自动启动后端与前端、等待服务就绪、确认 `/api` 代理连通，并打开浏览器。停止服务执行 `& './一键停止.ps1'`。参数：`-Demo` 用独立演示库、`-Background` 静默后台并写日志、`-Install` 先装依赖、`-NoBrowser` 不开浏览器、`-ApiPort` / `-WebPort` 指定端口。服务已运行时直接复用；端口被其他程序占用会明确报错。

### 分别启动

在项目根目录打开 PowerShell，启动后端：

```powershell
& './04.编码/后端/start.ps1'
```

另开一个 PowerShell，启动前端：

```powershell
& './04.编码/前端/start.ps1'
```

访问 `http://127.0.0.1:5173`。后端接口文档为 `http://127.0.0.1:8000/docs`，健康检查为 `/api/healthz`。前端默认将 `/api` 代理至本机 8000；需要其他地址时，仅为前端进程设置 `VITE_BACKEND_URL`。

后端读取本机 `.env` 中的 DB_HOST、DB_PORT、DB_USER、DB_PASSWORD、DB_NAME，或完整 DATABASE_URL。启动脚本只在 JWT 密钥缺失时生成 SECRET_KEY，保留已有密钥，不输出值。真实密码和 API Key 不进入前端或 Git。更改 `.env` 后需重启后端。

本机 MySQL 连接和现有 15 表字段已经核对成功。应用启动不执行 `schema.sql`、`init_data.sql` 或导出备份，不创建、重建或清空现有 MySQL。

## 预警演示步骤

1. 老人登录，确认授权，选择档案并录入血压。独立演示库可使用 185/100 验证高风险预警，测量时间填写当前时间。
2. 家属登录，先在个人中心确认授权，再进入通知中心；轮询周期为 30 秒，也可刷新。打开预警后仅标记该家属已读。
3. 在详情查看原始指标、参考范围和趋势。未配置 AI 时摘要显示失败，仍可登记联系、复诊或其他处理结果。
4. 提交处理说明后查看处理记录。提交时需同时给出处理动作（`CONTACTED` / `ARRANGED_VISIT` / `SENT_HOSPITAL` / `OBSERVE`）与处理说明。其他接收人能看到同一处理结果，其未读状态独立保存。
5. 解绑后再次请求该老人档案和预警，后端应立即拒绝；护工撤销分配也立即失权。绑定由家属发起、老人确认；解绑可由老人执行。

管理员可创建护工或管理员、启禁用户、维护角色、档案、指标录入范围、预警阈值和知识库。老人及家属自助注册不能获得护工或管理员角色。护工列表支持状态和测量时段筛选，按当前异常状态排序。

既有 MySQL 的部分旧阈值未覆盖低血压、低血糖范围。遇到未覆盖值时系统明确返回配置错误，不能将其判成正常。由管理员根据项目确认的规则补齐范围后再录入；代码不会自动篡改旧配置。独立演示配置已覆盖这些区间，阈值仍从 `sys_config` 读取。

## 关键接口字段速查

用 Postman 或脚本直接调接口时对照此表，避免字段名试错。完整定义见 `http://127.0.0.1:8000/docs`。

| 用途 | 方法与路径 | 必填请求体字段 |
| --- | --- | --- |
| 登录 | POST `/api/auth/login` | `phone`、`password` |
| 隐私授权 | POST `/api/auth/privacy-consent` | `accepted`（布尔） |
| 我的档案 | GET `/api/profiles` | 无 |
| 指标录入 | POST `/api/health/records` | `profile_id`、`type`、`values`、`measured_at` |
| 家属发起绑定 | POST `/api/family/bind` | `phone`、`relation`（`profile_id`、`note` 可选） |
| 老人确认绑定 | PUT `/api/family/bind/{bind_id}/confirm` | `action` |
| 通知中心 | GET `/api/notifications` | 无 |
| 预警详情 | GET `/api/alerts/{warning_id}` | 无 |
| 提交处理 | POST `/api/alerts/{warning_id}/handle` | `result`、`action`（两者都必填） |
| AI 咨询 | POST `/api/ai/chat` | `profile_id`、`question` |

补充说明：指标 `type` 取 `BLOOD_PRESSURE`、`BLOOD_SUGAR`、`HEART_RATE`、`SLEEP` 等，`BLOOD_PRESSURE` 的 `values` 含 `systolic` 与 `diastolic`。处理动作 `action` 仅接受 `CONTACTED`、`ARRANGED_VISIT`、`SENT_HOSPITAL`、`OBSERVE`。授权、绑定确认等接口对未授权或无权限账号分别返回 403 与错误码 1002，属正常权限校验。

## AI 和知识库配置

在后端 `.env` 设置 LLM_PROVIDER 为 deepseek、qwen 或 glm，并填写对应 DEEPSEEK_API_KEY、DASHSCOPE_API_KEY 或 ZHIPU_API_KEY。提供方切换不需要修改代码。模型地址与模型名称可通过 LLM_BASE_URL、LLM_MODEL 覆盖。

咨询采用 LangGraph 四条数据路径：日常问题只检索知识；数据问题查授权档案的真实指标；异常问题查具体预警和趋势；紧急表述由代码立即写预警并给出求助提示。模型不能执行 SQL、判断权限或写数据库。输入长度、日限额、超时、重试和输出安全过滤均由后端实现。

七类官方科普文件位于后端 `data/knowledge_seed.json`，包含 WHO 和 NHS 的来源链接及检索日期。独立演示库自动导入。对已有数据库，在后端目录先预览缺少的条目：

```powershell
.venv/Scripts/python.exe -m scripts.import_knowledge
```

确需追加时运行：

```powershell
.venv/Scripts/python.exe -m scripts.import_knowledge --apply
```

导入只追加缺少的条目，不覆盖管理员编辑，也不重新启用已禁用条目。当前已有 MySQL 未执行此导入。本次未配置真实模型 Key，尚未进行外部模型回答质量验收。

默认哈希 Embedding 加 Chroma 可离线运行，属于词形检索。可选本地 SentenceTransformer 适配器只加载已存在的完整模型目录，不自动下载；真实语义模型尚未验证。具体参数与边界见后端 `app/agent/README.md`。

## 测试与故障定位

后端目录执行单测和独立验收：

```powershell
.venv/Scripts/python.exe -m pytest tests -q
.venv/Scripts/python.exe -m pytest ../../05.集成测试 -q
```

项目根目录执行 MySQL 只读核对或临时库验收：

```powershell
$testPython = './04.编码/后端/.venv/Scripts/python.exe'
& $testPython './05.集成测试/verify_mysql.py'
& $testPython './05.集成测试/verify_mysql.py' --run-tests
```

后者创建随机命名的临时 MySQL 库，测试完仅删除此临时库，不重置已有业务库。浏览器测试脚本、结果和截图见 `05.集成测试/前端浏览器/README.md`。可复现依赖快照在后端 `requirements.lock.txt`。

默认生产服务不扫描遗留摘要。单进程需要时设置 SUMMARY_RECOVERY_ENABLED=true，超时遗留摘要转为失败后由用户重试；活动任务会被排除。多进程不启用此扫描，应使用外部任务协调后再部署。

【选配】短信验证码、电话外呼、流式输出、文档上传和 PDF 导出未接入。本地用药或打卡页面会明确标注未同步服务器，不列为核心验收成功。前端构建有 Element Plus 和 ECharts 包体较大的优化提示，不影响本次编译及浏览器验证。
