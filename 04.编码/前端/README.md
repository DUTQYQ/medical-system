## 启动

先启动 FastAPI 后端（默认 `127.0.0.1:8000`），再执行：

```powershell
cd 04.编码/前端
npm ci --no-audit --no-fund
npm run dev
```

访问 `http://127.0.0.1:5173`。开发服务器将 `/api` 转发到 `http://127.0.0.1:8000`；改端口可在当前进程设置 `VITE_BACKEND_URL`，再启动 Vite。前端不保存模型密钥。

构建：`npm run build`。生产环境托管 `dist/`，为 History 路由配置回退到 `index.html`，同时将 `/api` 反向代理到后端。`npm run preview` 仅用于构建产物预览。

## 核心功能

- 认证：真实密码/JWT 登录、角色导航、后端当前用户校验、过期/禁用退出、服务器退出登录、个人信息/密码修改与隐私授权。
- 老人：多份健康档案切换及增改删，五类指标录入和历史删除、动态阈值及趋势、家属确认/拒绝/解绑、咨询及历史、站内预警。
- 家属：绑定申请与历史、授权老人的概况/趋势/代录/咨询、通知和预警处理。
- 护工：责任老人按状态与测量时间筛选/详情/代录、预警中心与处理记录。实际数据范围由后端强制隔离。
- 管理员：账号创建/启禁/CARE与ADMIN角色维护、指标配置、预警阈值、知识增改删及索引重建、统计、绑定代审核与预警处理。

接口均经 `src/api/` 调用，统一响应成功解包 `data`，业务错误保留错误码与原因。已经移除内存 mock 登录和健康数据。服务器失联、AI不可用、没有记录和无权限均有独立提示，不把失败当保存成功。

站内未读数每30秒轮询。查看预警仅标记本人已读；提交真实处理结论后刷新处理记录；AI摘要失败不阻断处理。AI响应显示意图、Agent、安全级别、知识来源；未启用语义Embedding时显示检索限制。

## 【选配】边界

- 健康打卡、用药备忘仅按用户隔离保存在本机浏览器，页面明确说明未同步服务器；没有预填药品或虚构打卡。
- 日报/周报按实际测量时间过滤本周期记录，汇总数量、异常数量和最近值；无记录不能推断健康状态，没有伪造AI建议。
- 忘记密码、短信、语音、知识文件上传、PDF导出不在此版核心交付中。找回密码页面明确说明联系管理员，不返回假重置成功。

任何页面均显示“健康建议不构成医疗诊断”。阈值读取后端 `sys_config`，不在页面写死。初始测试账号与密码由后端演示初始化工具产生，前端不附带密码任意的演示账号。
